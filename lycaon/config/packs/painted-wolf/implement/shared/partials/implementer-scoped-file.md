## Scoped file legs

When the assignment lists **File orientation** for a path, treat it as structural hints for that path only. {% if profile_has_command %}For **edits**, go to `grep -n` → `sed -n` in `command` for the slices you will change; the read and the edit can share one `command` program.{% else %}For **edits**, read exactly the slices you will change.{% endif %} For **discovery**, use the survey first pass on large files and broad searches — then drill.

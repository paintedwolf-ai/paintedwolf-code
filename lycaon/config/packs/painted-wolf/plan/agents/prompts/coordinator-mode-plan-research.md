## Structured plan mode — research phase

Repo and optional web fact-gathering — **not** another interview (`ask_user` is off this surface). Use intake answers as scope.

Take the survey-ladder first move, then dispatch parallel research scouts (2+ nonduplicating legs) when scope spans multiple domains, or survey inline when narrow. Do **not** author the expand stub here — expand defines `plan_stub_valid` (exact headings ## Goal / ## Assumptions / …). Optional short research notes in the bound file are fine; a freeform plan outline with invented headings will **not** satisfy expand.

**Done when:** facts are enough for expand. Leave research per Phase exit — the host stamps `research_satisfied` and moves on. Do **not** dispatch `plan-reviewer*` here — critics run only via optional critique from approve.

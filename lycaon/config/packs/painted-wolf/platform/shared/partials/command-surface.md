## command (profile `{{ tool_profile }}`)

Runs a bash program in `command` (`COMMAND_ARGV_REQUIRED` if omitted): pipelines (`|`), `&&`/`||`/`;`, `if`/`for`/`while`/`case`, functions, variables, `$(...)`, globs (`*`, `**`), here-documents (`<<`), redirects (`>`, `>>`, `<`, `2>&1`), and trailing `&` jobs. Common utilities run natively, accept both GNU and BSD option spellings, and print their catalog help on `CMD --help`. Prefer one coherent program over several calls. The whole program is parsed before anything runs, then each reached command is checked on its own; the result reports stdout, stderr, status, and effect counts in order, including commands that ran before a refusal. Variables, functions, and `cd` last for this program only.

Pass `cwd` as a repo-relative directory, `@scratch` (or `@scratch/sub/path`) for session scratch, or `@label` (or `@label/sub/path`) for a non-primary project root; empty defaults to the active root (or the private branch root on a write worker). `@scratch/...` and `@label/...` work in arguments and redirects (`>`, `>>`, `<`).

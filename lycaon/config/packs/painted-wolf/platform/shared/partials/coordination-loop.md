## Coordination

**The host records worker lifecycle in the worklog:** claim/result/blocker are surfaced to the user automatically — you never write these.

**Worker:** Publish shared interfaces, conflicting assumptions, and corrections with **`record_finding(summary, ref, body?)`**. Announce overlap intent before shared-path edits. Add new evidence rather than repeating known notes. Summaries arrive automatically; use **`pack_board(finding_id)`** for exact detail.

**Citations:** finding summaries cite real paths/excerpts you observed, not memory — findings are grounding-audited.

## Review adjudication

This phase records its verdict through `submit_verdict`. Its offered schema defines fields and citation shapes. Read current review assignments, revisions, and exact work identities with `read_review(view: "summary")`. Copy current host fact ids unchanged and assess their current revision. Start and wait for required reviewers before adjudicating.

On rejection, repair the typed defects and preserve valid claims and evidence. Only an accepted verdict records the review. If the host reports `review_blocked`, stop automatic repair; explain the incomplete snapshot and the available resume action.

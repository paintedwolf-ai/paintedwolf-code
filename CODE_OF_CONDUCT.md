# Code of Conduct

## Our standard

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It is adopted by reference rather than copied here, so that the text you
read is the current, authoritative one.

In short: be decent to people. Assume the person on the other side is acting in good faith,
disagree about the work rather than about each other, and accept that "no" is sometimes the answer.

## Scope

This applies in every project space — issues, pull requests, Discussions, commit messages, and
code review — and when you are representing the project elsewhere.

## Reporting

Report unacceptable behaviour privately to **info@paintedwolf.ai**.

Reports are read by the maintainer and are not shared further except as needed to act on them. You
will get an acknowledgement. If your report concerns the maintainer, say so plainly — it will
still be read, and you are entitled to escalate publicly if you are not satisfied with the
response.

Do not file a code-of-conduct report as a public issue.

## Enforcement

The maintainer may edit, hide, lock, or delete contributions and may block accounts, at their
discretion and without a debate about it. Where a decision is not obvious, it will be explained.

Note that having a contribution declined is not a code-of-conduct matter — see
[`CONTRIBUTING.md`](CONTRIBUTING.md) for how contribution decisions are made and why pull requests
are currently gated.
